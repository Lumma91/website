# Video · Lumma Films

Colocar aquí los archivos de video de la página /films:

- `films-hero.mp4` — bucle corto para el fondo del hero (sin audio, 10–20 s, comprimido para web).
- `films-teaser.mp4` — teaser de marca (45–75 s, con audio; se reproduce silenciado con controles).

Mientras estos archivos no existan, la página muestra las imágenes de poster.
Al subirlos con estos nombres exactos, el video aparece sin tocar el código.
